## Short description (limit 1000)

3D viewer and editor for Minecraft schematics on Windows. It imports .litematic, .schem, .schematic and .nbt files, keeps them in a local library, shows them in 3D and works out the materials needed to build them. Works offline.

## Description (limit 10,000)

Schematic Lab is a desktop app for people who keep Minecraft builds as schematics. You open them, look at them in 3D and find out which materials you need to build them.

It imports four formats: .litematic, .schem, .schematic and .nbt. The format is recognised from the contents of the file, not from its extension, so an .nbt that is really an old schematic opens just the same. Each schematic is copied into a local library with a thumbnail; your original file is never touched.

The 3D viewer lets you rotate the model, inspect blocks one by one and cut it by layers to see the inside. If you have Minecraft Java Edition installed, it uses its textures, read from the game's jar; if not, each block is drawn in its average colour.

The materials list is calculated in three modes: exact count, in stacks and in shulker boxes. You can limit it to a region or a range of layers, tick off what you have already gathered and export it to CSV.

Edit mode lets you change a single block, or replace every block of one type with a similar one, or with its whole family. Each change is saved as .litematic over the library copy and keeps a history of 20 versions, so you can undo, redo, restore and export.

Privacy: the app sends no data anywhere, has no accounts and no telemetry, and works offline. It only reads the files you point it at, the .minecraft folder (to find the installed versions) and the Minecraft jar (for textures). Its library is stored in the data folder Windows reserves for the app, which is removed when you uninstall it, and deleting a schematic sends it to the Windows Recycle Bin.

Requirements: Windows 10 (version 2004 or later) or Windows 11, 64-bit (x64). Textures need Minecraft Java Edition installed; without it the app works with flat colours.

## Features (limit 20 x 200)

1. Imports .litematic, .schem, .schematic and .nbt, detected by their contents.
2. Local library with thumbnails; deleting sends the file to the Recycle Bin.
3. 3D viewer with rotation, block inspection and layer cutting.
4. Materials in three modes: exact, in stacks and in shulker boxes.
5. Tick boxes for what you have already gathered and CSV export of the list.
6. Edit mode: single-block changes and replacing a block or its whole family.
7. History of 20 versions per schematic, with restore and export.
8. Real textures if Minecraft is installed; otherwise an average colour per block.
9. Offline, no accounts, no telemetry.
